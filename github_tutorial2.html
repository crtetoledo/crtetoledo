Tutorial: Do Seu PC para o GitHub com Token de Acesso

Um guia completo para enviar seus arquivos locais para um repositório no GitHub, usando o método de autenticação mais seguro e atual: o Personal Access Token (PAT).

Pré-requisitos

  1. Git instalado no seu computador.
  2. Uma conta criada no GitHub.

Etapa 1: Gerar seu Personal Access Token (PAT)

Este token será sua senha para usar no terminal. Você só precisa fazer isso uma vez (ou sempre que o token expirar).

  1. Acesse as Configurações: Faça login no GitHub, clique na sua foto de perfil no canto superior direito e vá para Settings.
  2. Vá para as Configurações de Desenvolvedor: No menu esquerdo, role até o final e clique em Developer settings.
  3. Abra a Seção de Tokens: Clique em Personal access tokens e depois em Tokens (classic).
  4. Gere um Novo Token: Clique no botão Generate new token e depois em Generate new token (classic).
  5. Configure o Token:
    • Note (Nome): Dê um nome descritivo. Ex: Token para meu Notebook.
    • Expiration (Expiração): Defina um prazo de validade (ex: 90 dias).
    • Select scopes (Permissões): Marque a caixa de seleção repo. Isso dará ao token todas as permissões necessárias.

  6. Crie e Copie o Token: Role até o final e clique em Generate token.
    IMPORTANTE: Copie o token (ghp_...) imediatamente e guarde-o em um lugar seguro. Você nunca mais o verá novamente!

Etapa 2: Criar o Repositório no GitHub

Este será o "lar" do seu projeto na nuvem.

  1. Novo Repositório: No canto superior direito do GitHub, clique no ícone + e selecione New repository.
  2. Preencha os Detalhes: Dê um nome, escolha entre Público/Privado e deixe todas as caixas de inicialização desmarcadas.
  3. Crie o Repositório: Clique no botão verde Create repository.
  4. Guarde a URL: Na página seguinte, copie a URL do seu repositório. Ela será no formato https://github.com/seu-usuario/nome-do-repo.git.

Etapa 3: Preparar e Enviar seu Projeto Local

Agora, vamos ao seu computador. Abra o terminal (ou Git Bash) dentro da pasta do seu projeto.

  1. Inicie o Git: Se o projeto nunca usou Git, execute: 
    git init
  2. Adicione os Arquivos: Para preparar todos os arquivos para serem salvos: 
    git add .
  3. Faça o "Commit": Salve uma "fotografia" do estado atual do seu projeto: 
    git commit -m "Commit inicial do projeto"
  4. Conecte seu Computador ao GitHub: (Use a URL que você copiou na Etapa 2) 
    git remote add origin https://github.com/seu-usuario/nome-do-repo.git
  5. Envie os Arquivos (O Momento da Autenticação): 
    git push -u origin master
  6. Faça o Login no Terminal:
    • Quando pedir Username, digite seu nome de usuário do GitHub e pressione Enter.
    • Quando pedir Password, cole o Personal Access Token (PAT) que você gerou na Etapa 1.
    Atenção: Ao colar a senha/token, nada aparecerá na tela por segurança. Apenas cole e pressione Enter. Geralmente, você só precisa fazer isso na primeira vez!

Pronto!

Seus arquivos foram enviados com sucesso! Atualize a página do seu repositório no GitHub e você verá todo o seu projeto lá.
